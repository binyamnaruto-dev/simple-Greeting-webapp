# simple-Greeting-webapp
P8 (Greeting Web App)  This project is a simple and clean greeting system.  Features:  - Time-based greeting system. - Name filtering system that prevents users from entering numbers and special characters. - Prevents users from entering single letters (a-z). - Simple and clean UI. - if user not enter name it display user input with Sir!. and lot.
